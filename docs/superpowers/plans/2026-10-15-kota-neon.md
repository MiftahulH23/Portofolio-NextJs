# Kota Neon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/` an interactive "Kota Neon" world: visitors ride a bicycle freely around a neon night city that has six information gates and eight billboards. Design D moves to `/ringkas`, and its hero cube becomes floating interactive 3D dev icons.

**Architecture:**
- All world logic (city layout, road graph, bike physics, collision, traffic, pedestrians, gates, billboards, minimap, store) lives in pure TypeScript under `src/world/`, unit-tested in Node.
- React Three Fiber components under `src/components/world/` draw that state. They mutate a shared `runtime` object each frame instead of React state.
- DOM HUD components under `src/components/hud/` subscribe to a small `useSyncExternalStore` store.
- The world chunk is lazy-loaded from a server-rendered intro.

**Tech Stack:** Next.js 16.1 (App Router, Turbopack), React 19.2, TypeScript, Tailwind v4, three 0.180, @react-three/fiber 9, @react-three/drei 10, **@react-three/postprocessing 3** (new), Vitest 5 + Testing Library, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-15-kota-neon-design.md`

**Visual reference:** `docs/superpowers/prototypes/kota-neon-v3.html` (the approved prototype, three r128 single file). When a visual detail is unclear, match the prototype. Its constants were tuned with the user.

## Global Constraints

- Work on branch `feat/kota-neon` created from `feat/redesign-d`. **Never `git push`**: pushing deploys to Vercel and needs the user's explicit OK.
- The only new dependency is `@react-three/postprocessing@3.0.4`. Do not upgrade existing packages.
- **Never invent content.** Every fact on gates and billboards comes from `src/content/*` (`getContent(lang)`). UI copy lives in `src/content/ui.ts` (`uiEn` and `uiId`). The `UiStrings` type forces EN/ID key parity.
- Copy is professional in both languages, with no slang and no jokes.
- Traffic drives on the **left** (Indonesia).
- Respect `prefers-reduced-motion`: no idle camera orbit, no ring spin, no sign flicker, no screen shake. Intro recommends `/ringkas`.
- Per-frame state lives in refs or the `runtime` object. React state is never updated every frame. Store values are rounded or deduplicated before notifying.
- Every `dt` used by simulation is clamped to `≤ 1/30` s.
- Performance targets: desktop high tier ≥ 55 fps; mid phone low tier ≥ 30 fps; `/` LCP ≤ 2.5 s (Lighthouse mobile); 3D code not in the `/` initial bundle; `/ringkas` keeps Performance ≥ 85, Accessibility ≥ 95, SEO ≥ 95.
- Commit after each task with the message given, ending with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Lint rule `react-hooks/immutability` (verified on this repo):** never assign properties of a `useMemo`/`useState` value or a `useThree()` value directly in a component (`mat.opacity = x` and `camera.fov += x` both fail lint). Allowed alternatives are method calls (`.set()`, `.copy()`, `.lerp()`), objects reached through `ref.current`, or a module-level helper function that takes the object as a parameter (`applyBikePose(model, …)`). The plan's code follows this. Keep it that way when you change code.
- Commands: `npm run lint`, `npm run test`, `npm run build`, `npm run test:e2e` must all be green at the end.

## Review Focus

1. **Keys held while the tab loses focus** (alt-tab mid-ride) would leave the bike riding forever. Expect all inputs released on `blur` and on `visibilitychange` to hidden. *Test:* Task 6 `useKeyboardInput.test.tsx`.
2. **A huge frame gap** (tab restored after minutes) could tunnel the bike through a building. Expect `dt` clamped so a single step moves ≤ 32/30 units and collision still resolves. *Test:* Task 3 `bike.test.ts` "clamps dt".
3. **Jitter on a gate's edge** (stopping half inside) could reopen the card every frame. Expect one open per real pass, using exit hysteresis. *Test:* Task 4 `gates.test.ts` "hysteresis".
4. **Language switch while riding** must update the open card, HUD and billboard textures. *Test:* Task 7 `InfoCard.test.tsx` "follows language"; billboards are re-keyed on `lang` in Task 9 and checked visually.
5. **Blocked `localStorage`** (private mode) must not crash the mute toggle; it falls back to memory. *Test:* Task 4 `store.test.ts` "storage throws".

/** Flat SVG version of the floating icons: CSS float + pointer parallax; static under reduced motion. */
export function FloatingIconsCss() {
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const el = ref.current;
    if (!el || window.matchMedia("(prefers-reduced-motion: reduce)").matches) return;
    function move(e: PointerEvent) {
      const r = el!.getBoundingClientRect();
      const px = (e.clientX - r.left) / r.width - 0.5;
      const py = (e.clientY - r.top) / r.height - 0.5;
      el!.style.setProperty("--px", String(px));
      el!.style.setProperty("--py", String(py));
    }
    window.addEventListener("pointermove", move);
    return () => window.removeEventListener("pointermove", move);
  }, []);

  return (
    <div ref={ref} aria-hidden="true" className="relative size-full">
      {ICONS.map((icon, i) => {
        const [x, y, z] = HOMES[i];

            className="absolute flex size-16 items-center justify-center rounded-2xl border border-ink-600 bg-ink-850/80 text-lime shadow-[0_0_24px_rgba(163,230,53,.18)] motion-safe:animate-float"

"use client";

import { useMemo, useRef } from "react";
import { Canvas, useFrame, useThree, type ThreeEvent } from "@react-three/fiber";
import { CatmullRomCurve3, Group, MeshStandardMaterial, Plane, Raycaster, TubeGeometry, Vector3 } from "three";
import { SVGLoader } from "three/examples/jsm/loaders/SVGLoader.js";
import { HOMES, ICONS } from "./icon-paths";

const LIME = "#A3E635";
const INK = "#F4F4F5";

function setGlow(m: MeshStandardMaterial, on: boolean) {
  m.emissiveIntensity = on ? 0.9 : 0.35;
}

function iconGeometries(paths: string[]): TubeGeometry[] {
  const loader = new SVGLoader();
  const svg = `<svg xmlns="http://www.w3.org/2000/svg">${paths.map((d) => `<path d="${d}"/>`).join("")}</svg>`;
  const out: TubeGeometry[] = [];
  for (const shapePath of loader.parse(svg).paths) {
    for (const sub of shapePath.subPaths) {
      const pts = sub.getPoints(32).map((p) => new Vector3((p.x - 12) / 12, (12 - p.y) / 12, 0));
      if (pts.length < 2) continue;
      const curve = new CatmullRomCurve3(pts, false, "catmullrom", 0.05);
      out.push(new TubeGeometry(curve, Math.max(24, pts.length * 3), 0.085, 10, false));
    }
  }
  return out;
}

interface Body {
  home: Vector3;
  pos: Vector3;
  vel: Vector3;
  spin: number;
  scale: number;
  hover: boolean;
  drag: boolean;
  phase: number;
}

function Icons({ active, reduce }: { active: boolean; reduce: boolean }) {
  const { camera, pointer, size } = useThree();
  const groups = useRef<(Group | null)[]>([]);
  const geos = useMemo(() => ICONS.map((i) => iconGeometries(i.paths)), []);
  const mats = useMemo(
    () => ICONS.map((_, i) => new MeshStandardMaterial({ color: i % 2 ? INK : LIME, emissive: i % 2 ? "#3f3f46" : LIME, emissiveIntensity: 0.35, roughness: 0.3, metalness: 0.2 })),
    [],
  );
  const bodies = useRef<Body[]>(
    HOMES.map(([x, y, z], i) => ({ home: new Vector3(x, y, z), pos: new Vector3(x, y, z), vel: new Vector3(), spin: 0, scale: 1, hover: false, drag: false, phase: i * 1.7 })),
  );
  const plane = useMemo(() => new Plane(new Vector3(0, 0, 1), 0), []);
  const ray = useMemo(() => new Raycaster(), []);
  const hit = useMemo(() => new Vector3(), []);
  const last = useRef({ t: 0, p: new Vector3() });
  const ndc = useMemo(() => new Vector3(), []);

  useFrame((state, rawDt) => {
    if (!active) return;
    const dt = Math.min(rawDt, 1 / 30);
    const t = state.clock.elapsedTime;
    bodies.current.forEach((b, i) => {
      const g = groups.current[i];
      if (!g) return;
      if (b.drag) {
        ray.setFromCamera(pointer, camera);
        if (ray.ray.intersectPlane(plane, hit)) {
          const now = performance.now();
          const span = Math.max(1, now - last.current.t) / 1000;
          b.vel.copy(hit).sub(last.current.p).divideScalar(span).clampLength(0, 18);
          last.current = { t: now, p: hit.clone() };
          b.pos.copy(hit);
        }
      } else {
        const target = b.home.clone();
        if (!reduce) {
          target.y += Math.sin(t * 0.9 + b.phase) * 0.18;
          target.x += pointer.x * 0.35 * (1 + b.home.z * 0.3);
          target.y += pointer.y * 0.25 * (1 + b.home.z * 0.3);
          ndc.copy(b.pos).project(camera);
          const dx = ndc.x - pointer.x, dy = ndc.y - pointer.y;
          const d = Math.hypot(dx * (size.width / size.height), dy);
          if (d < 0.28) target.add(new Vector3(dx, dy, 0).normalize().multiplyScalar((0.28 - d) * 4));
        }
        const acc = target.sub(b.pos).multiplyScalar(40).addScaledVector(b.vel, -8);
        b.vel.addScaledVector(acc, dt);
        b.pos.addScaledVector(b.vel, dt);
      }
      b.spin *= Math.exp(-dt * 2.5);
      const wantScale = b.hover || b.drag ? 1.25 : 1;
      b.scale += (wantScale - b.scale) * Math.min(1, dt * 10);
      g.position.copy(b.pos);
      g.scale.setScalar(b.scale);
      g.rotation.y += (reduce ? 0 : 0.25) * dt + b.spin * dt;
      g.rotation.x = reduce ? 0 : Math.sin(t * 0.6 + b.phase) * 0.25;
      setGlow(mats[i], b.hover || b.drag);
    });
  });

  function down(i: number, e: ThreeEvent<PointerEvent>) {
    e.stopPropagation();
    (e.target as Element | null)?.setPointerCapture?.(e.pointerId);
    const b = bodies.current[i];
    b.drag = true;
    last.current = { t: performance.now(), p: b.pos.clone() };
    document.body.style.cursor = "grabbing";
  }
  function up(i: number) {
    const b = bodies.current[i];
    if (!b.drag) return;
    b.drag = false;
    if (b.vel.length() < 0.5) b.spin += 14;
    document.body.style.cursor = b.hover ? "pointer" : "";
  }

  return (
    <>
      {ICONS.map((icon, i) => (
        <group
          key={icon.name}
          ref={(g) => {
            groups.current[i] = g;
          }}
          onPointerOver={(e) => {
            e.stopPropagation();
            bodies.current[i].hover = true;
            document.body.style.cursor = "pointer";
          }}
          onPointerOut={() => {
            bodies.current[i].hover = false;
            if (!bodies.current[i].drag) document.body.style.cursor = "";
          }}
          onPointerDown={(e) => down(i, e)}
          onPointerUp={() => up(i)}
          onPointerMissed={() => up(i)}
        >
          {geos[i].map((geo, k) => (
            <mesh key={k} geometry={geo} material={mats[i]} />
          ))}
          <mesh visible={false}>
            <sphereGeometry args={[1.05, 8, 8]} />
          </mesh>
        </group>
      ))}
    </>
  );
}

export default function FloatingIcons({ active = true, onContextLost }: { active?: boolean; onContextLost?: () => void }) {
  const reduce = typeof window !== "undefined" && window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  return (
    <Canvas
      dpr={[1, 2]}
      camera={{ position: [0, 0, 9], fov: 40 }}
      frameloop={active ? "always" : "demand"}
      onCreated={({ gl }) => {
        gl.domElement.addEventListener("webglcontextlost", (e) => {
          e.preventDefault();
          onContextLost?.();
        });
      }}
      onPointerUp={() => (document.body.style.cursor = "")}
    >
      <ambientLight intensity={0.6} />
      <directionalLight position={[4, 6, 8]} intensity={2.2} />
      <pointLight position={[-4, -2, 4]} intensity={30} color={LIME} />
      <Icons active={active} reduce={reduce} />
    </Canvas>
  );
}

export type Rand = () => number;

/** Small deterministic PRNG so the city looks the same on every visit and in tests. */
export function mulberry32(seed: number): Rand {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export const between = (r: Rand, a: number, b: number) => a + r() * (b - a);

export function pick<T>(r: Rand, arr: readonly T[]): T {
  return arr[Math.floor(r() * arr.length)];
}

import { CORNER_INSET, GRID, LANE_OFFSET, N, type Vec2 } from "./city";
import { pick, type Rand } from "./random";

export type NodeId = readonly [number, number];

export interface LinePiece { kind: "line"; p0: Vec2; p1: Vec2; dir: Vec2; len: number }
export interface TurnPiece { kind: "turn"; p0: Vec2; p1: Vec2; p2: Vec2; len: number; next: NodeId }
export type Piece = LinePiece | TurnPiece;

export const nodePos = (n: NodeId): Vec2 => ({ x: GRID[n[0]], z: GRID[n[1]] });
export const sameNode = (a: NodeId, b: NodeId) => a[0] === b[0] && a[1] === b[1];

export function neighbors(n: NodeId): NodeId[] {
  return ([[1, 0], [-1, 0], [0, 1], [0, -1]] as const)
    .map(([a, b]) => [n[0] + a, n[1] + b] as const)
    .filter(([a, b]) => a >= 0 && a < N && b >= 0 && b < N);
}

/** Left-hand side of a heading (Indonesia keeps left). */
export const laneSide = (d: Vec2): Vec2 => ({ x: d.z, z: -d.x });

const norm = (v: Vec2): Vec2 => {
  const l = Math.hypot(v.x, v.z) || 1;
  return { x: v.x / l, z: v.z / l };
};
const add = (a: Vec2, b: Vec2, s = 1): Vec2 => ({ x: a.x + b.x * s, z: a.z + b.z * s });

export function linePiece(from: NodeId, to: NodeId): LinePiece {
  const A = nodePos(from), B = nodePos(to);
  const dir = norm({ x: B.x - A.x, z: B.z - A.z }), s = laneSide(dir);
  const p0 = add(add(A, dir, CORNER_INSET), s, LANE_OFFSET);
  const p1 = add(add(B, dir, -CORNER_INSET), s, LANE_OFFSET);
  return { kind: "line", p0, p1, dir, len: Math.hypot(p1.x - p0.x, p1.z - p0.z) };
}

export function bezier(p0: Vec2, p1: Vec2, p2: Vec2, t: number): Vec2 {
  const u = 1 - t;
  return { x: u * u * p0.x + 2 * u * t * p1.x + t * t * p2.x, z: u * u * p0.z + 2 * u * t * p1.z + t * t * p2.z };
}

export function bezierTangent(p0: Vec2, p1: Vec2, p2: Vec2, t: number): Vec2 {
  const u = 1 - t;
  return norm({ x: 2 * u * (p1.x - p0.x) + 2 * t * (p2.x - p1.x), z: 2 * u * (p1.z - p0.z) + 2 * t * (p2.z - p1.z) });
}

export function turnPiece(from: NodeId, at: NodeId, to: NodeId): TurnPiece {
  const B = nodePos(at);
  const d1 = norm({ x: B.x - nodePos(from).x, z: B.z - nodePos(from).z });
  const d2 = norm({ x: nodePos(to).x - B.x, z: nodePos(to).z - B.z });
  const s1 = laneSide(d1), s2 = laneSide(d2);
  const p0 = add(add(B, d1, -CORNER_INSET), s1, LANE_OFFSET);
  const p2 = add(add(B, d2, CORNER_INSET), s2, LANE_OFFSET);
  const straight = d1.x * d2.x + d1.z * d2.z > 0.5;
  const p1 = straight ? add(B, s1, LANE_OFFSET) : add(add(B, s1, LANE_OFFSET), s2, LANE_OFFSET);
  let len = 0, prev = p0;
  for (let k = 1; k <= 12; k++) {
    const q = bezier(p0, p1, p2, k / 12);
    len += Math.hypot(q.x - prev.x, q.z - prev.z);
    prev = q;
  }
  return { kind: "turn", p0, p1, p2, len, next: to };
}

export function samplePiece(p: Piece, d: number): { pos: Vec2; tan: Vec2 } {
  const t = Math.min(1, Math.max(0, d / p.len));
  if (p.kind === "line") return { pos: { x: p.p0.x + (p.p1.x - p.p0.x) * t, z: p.p0.z + (p.p1.z - p.p0.z) * t }, tan: p.dir };
  return { pos: bezier(p.p0, p.p1, p.p2, t), tan: bezierTangent(p.p0, p.p1, p.p2, t) };
}

export function chooseNext(from: NodeId, at: NodeId, r: Rand): NodeId {
  const all = neighbors(at);
  const options = all.filter((n) => !sameNode(n, from));
  return pick(r, options.length ? options : all);
}

import type { Circle, Rect } from "./city";

export const BIKE_RADIUS = 0.6;

/** Pushes a point (with radius r) out of boxes and circles and keeps it inside the city. */
export function resolveCollisions(
  x: number, z: number, rects: readonly Rect[], circles: readonly Circle[], bounds: { lo: number; hi: number }, r = BIKE_RADIUS,
): { x: number; z: number; hit: boolean } {
  let hit = false;
  for (const b of rects) {
    if (x > b.x0 - r && x < b.x1 + r && z > b.z0 - r && z < b.z1 + r) {
      const pen = [x - (b.x0 - r), b.x1 + r - x, z - (b.z0 - r), b.z1 + r - z];
      const k = pen.indexOf(Math.min(...pen));
      if (k === 0) x = b.x0 - r;
      else if (k === 1) x = b.x1 + r;
      else if (k === 2) z = b.z0 - r;
      else z = b.z1 + r;
      hit = true;
    }
  }
  for (const c of circles) {
    const dx = x - c.x, dz = z - c.z, d = Math.hypot(dx, dz), min = c.r + r;
    if (d < min && d > 1e-6) {
      x = c.x + (dx / d) * min;
      z = c.z + (dz / d) * min;
      hit = true;
    }
  }
  const lo = bounds.lo + r, hi = bounds.hi - r;
  if (x < lo || x > hi || z < lo || z > hi) {
    x = Math.min(hi, Math.max(lo, x));
    z = Math.min(hi, Math.max(lo, z));
    hit = true;
  }
  return { x: Math.round(x * 1e9) / 1e9, z: Math.round(z * 1e9) / 1e9, hit };
}

import type { Vec2 } from "./city";

export interface BikeInput { gas: boolean; brake: boolean; left: boolean; right: boolean; boost: boolean }
export interface BikeState { x: number; z: number; heading: number; v: number; steer: number; lean: number; crank: number }

/** Tuned in the approved prototype (docs/superpowers/prototypes/kota-neon-v3.html). */
export const BIKE = {
  max: 22, boostMax: 32, accel: 11, boostAccel: 16, brake: 24, reverse: 6, drag: 0.28, rolling: 0.9,
  minV: -5, steerResponse: 7, turnRate: 1.55, leanMax: 0.42, maxDt: 1 / 30,
} as const;

export const createBike = (x: number, z: number, heading: number): BikeState => ({ x, z, heading, v: 0, steer: 0, lean: 0, crank: 0 });
export const forward = (heading: number): Vec2 => ({ x: Math.sin(heading), z: Math.cos(heading) });
export const kmh = (v: number) => Math.round(Math.abs(v) * 1.6);

export function stepBike(s: BikeState, input: BikeInput, rawDt: number): BikeState {
  const dt = Math.min(Math.max(rawDt, 0), BIKE.maxDt);
  const cap = input.boost ? BIKE.boostMax : BIKE.max;
  let v = s.v;
  const acc = input.gas ? (input.boost ? BIKE.boostAccel : BIKE.accel) * (1 - (Math.max(0, v) / cap) * 0.6) : 0;
  const brk = input.brake ? (v > 0.3 ? BIKE.brake : BIKE.reverse) : 0;
  v += (acc - brk - v * BIKE.drag - (Math.abs(v) > 0.05 ? Math.sign(v) * BIKE.rolling : 0)) * dt;
  if (!input.gas && !input.brake && Math.abs(v) < 0.1) v = 0;
  v = Math.min(cap, Math.max(BIKE.minV, v));

  const target = (input.left ? 1 : 0) - (input.right ? 1 : 0);
  const steer = s.steer + (target - s.steer) * Math.min(1, dt * BIKE.steerResponse);
  const grip = Math.min(1, Math.abs(v) / 3) * (1 - Math.min(Math.abs(v), 32) / 70);
  const heading = s.heading + steer * BIKE.turnRate * grip * (v < 0 ? -1 : 1) * dt;
  const f = forward(heading);
  const lean = s.lean + (-steer * BIKE.leanMax * Math.min(1, Math.abs(v) / 9) - s.lean) * Math.min(1, dt * 5);
  const crank = s.crank + Math.max(0, v) * dt * 1.5 + (input.gas ? dt * 2 : 0);
  return { x: s.x + f.x * v * dt, z: s.z + f.z * v * dt, heading, v, steer, lean, crank };
}

import type { Vec2 } from "./city";
import { chooseNext, linePiece, neighbors, samplePiece, turnPiece, type NodeId, type Piece } from "./graph";
import { between, pick, type Rand } from "./random";

export interface Car {
  from: NodeId; to: NodeId; piece: Piece; d: number; v: number; cruise: number;
  wait: number; ignore: number; honk: number; pos: Vec2; tan: Vec2; color: number; taxi: boolean;
}

export const CAR_COLORS = [0xe23d6b, 0x2fb5ff, 0xf4f1ff, 0xffc93d, 0x7b5cff, 0x22d39a, 0x1d1b2c, 0xff8a3d] as const;
export const CAR_RADIUS = 2.4;
const MAX_DT = 1 / 30;

export function spawnCars(n: number, r: Rand): Car[] {
  const cars: Car[] = [];
  for (let k = 0; k < n; k++) {
    let from: NodeId;
    do from = [Math.floor(r() * 5), Math.floor(r() * 5)] as const;
    while (from[0] === 2 && from[1] === 2);
    const to = pick(r, neighbors(from));
    const piece = linePiece(from, to);
    const d = Math.min(between(r, 0, 40), piece.len - 1);
    const s = samplePiece(piece, d);
    const cruise = between(r, 9, 13);
    cars.push({ from, to, piece, d, v: cruise, cruise, wait: 0, ignore: 0, honk: 0, pos: s.pos, tan: s.tan, color: pick(r, CAR_COLORS), taxi: r() < 0.25 });
  }
  return cars;
}

function ahead(pos: Vec2, tan: Vec2, other: Vec2) {
  const rx = other.x - pos.x, rz = other.z - pos.z;
  return { along: rx * tan.x + rz * tan.z, lateral: Math.abs(rx * tan.z - rz * tan.x) };
}

export function stepTraffic(cars: Car[], bike: Vec2, rawDt: number, r: Rand): { honked: boolean } {
  const dt = Math.min(Math.max(rawDt, 0), MAX_DT);
  let honked = false;
  for (const c of cars) {
    let blocked = false;
    const b = ahead(c.pos, c.tan, bike);
    if (b.along > 0 && b.along < 10 && b.lateral < 2.6) {
      blocked = true;
      c.honk += dt;
      if (c.honk > 1.2) {
        c.honk = -3;
        honked = true;
      }
    } else c.honk = Math.min(c.honk, 0);

    if (c.ignore > 0) c.ignore -= dt;
    else
      for (const o of cars) {
        if (o === c) continue;
        const a = ahead(c.pos, c.tan, o.pos);
        if (a.along > 0 && a.along < 7.5 && a.lateral < 1.8) {
          blocked = true;
          break;
        }
      }

    c.wait = blocked && c.v < 0.3 ? c.wait + dt : 0;
    if (c.wait > 3) {
      c.ignore = 1.5;
      c.wait = 0;
    }
    const want = blocked && c.ignore <= 0 ? 0 : c.cruise * (c.piece.kind === "line" ? 1 : 0.6);
    c.v += (want - c.v) * Math.min(1, dt * (want === 0 ? 5 : 1.5));
    c.d += c.v * dt;
    while (c.d >= c.piece.len) {
      c.d -= c.piece.len;
      if (c.piece.kind === "line") c.piece = turnPiece(c.from, c.to, chooseNext(c.from, c.to, r));
      else {
        const next = c.piece.next;
        c.from = c.to;
        c.to = next;
        c.piece = linePiece(c.from, c.to);
      }
    }
    const s = samplePiece(c.piece, c.d);
    c.pos = s.pos;
    c.tan = s.tan;
  }
  return { honked };
}

export function pushBikeFromCars(x: number, z: number, cars: readonly Car[]): { x: number; z: number; hit: boolean } {
  let hit = false;
  for (const c of cars) {
    const dx = x - c.pos.x, dz = z - c.pos.z, d = Math.hypot(dx, dz);
    if (d < CAR_RADIUS) {
      const nx = d > 1e-6 ? dx / d : 1, nz = d > 1e-6 ? dz / d : 0;
      x = c.pos.x + nx * CAR_RADIUS;
      z = c.pos.z + nz * CAR_RADIUS;
      hit = true;
    }
  }
  return { x, z, hit };
}

import { BLOCKS, SIDEWALK, type Block, type Vec2 } from "./city";
import { between, pick, type Rand } from "./random";

export interface Ped {
  block: number; u: number; speed: number; pause: number; phase: number;
  x: number; z: number; facing: number; shirt: number; skin: number; phone: boolean;
}

const SHIRTS = [0xff6b9a, 0x5fd3ff, 0xffd166, 0xb6f23a, 0xc4a7ff, 0xf4f1ff, 0xff8a3d] as const;
const SKINS = [0xc98f6b, 0xa8704f, 0xe0b08e] as const;
const MAX_DT = 1 / 30;

function inner(b: Block) {
  return { x0: b.x0 + SIDEWALK / 2, x1: b.x1 - SIDEWALK / 2, z0: b.z0 + SIDEWALK / 2, z1: b.z1 - SIDEWALK / 2 };
}

export function perimeter(b: Block): number {
  const r = inner(b);
  return 2 * (r.x1 - r.x0 + (r.z1 - r.z0));
}

export function perimeterPoint(b: Block, u: number): { x: number; z: number; dx: number; dz: number } {
  const r = inner(b), w = r.x1 - r.x0, h = r.z1 - r.z0, P = 2 * (w + h);
  u = ((u % P) + P) % P;
  if (u < w) return { x: r.x0 + u, z: r.z0, dx: 1, dz: 0 };
  if (u < w + h) return { x: r.x1, z: r.z0 + (u - w), dx: 0, dz: 1 };
  if (u < 2 * w + h) return { x: r.x1 - (u - w - h), z: r.z1, dx: -1, dz: 0 };
  return { x: r.x0, z: r.z1 - (u - 2 * w - h), dx: 0, dz: -1 };
}

function place(p: Ped) {
  const pt = perimeterPoint(BLOCKS[p.block], p.u);
  const s = Math.sign(p.speed) || 1;
  p.x = pt.x;
  p.z = pt.z;
  p.facing = Math.atan2(pt.dx * s, pt.dz * s);
}

export function spawnPeds(n: number, r: Rand): Ped[] {
  return Array.from({ length: n }, () => {
    const p: Ped = {
      block: Math.floor(r() * BLOCKS.length), u: between(r, 0, 220), speed: between(r, 1, 1.6) * (r() < 0.5 ? 1 : -1),
      pause: 0, phase: between(r, 0, 6), x: 0, z: 0, facing: 0, shirt: pick(r, SHIRTS), skin: pick(r, SKINS), phone: r() < 0.35,
    };
    place(p);
    return p;
  });
}

export function stepPeds(peds: Ped[], bike: Vec2, bikeSpeed: number, rawDt: number): { nearMiss: boolean } {
  const dt = Math.min(Math.max(rawDt, 0), MAX_DT);
  let nearMiss = false;
  for (const p of peds) {
    const d = Math.hypot(bike.x - p.x, bike.z - p.z);
    if (d < 1.4) {
      p.pause = Math.max(p.pause, 1.2);
      if (Math.abs(bikeSpeed) > 3) nearMiss = true;
    }
    if (p.pause > 0) p.pause -= dt;
    else p.u += p.speed * dt;
    place(p);
  }
  return { nearMiss };
}

export const GATE_KEYS: GateKey[] = ["profile", "skills", "experience", "projects", "education", "contact"];

export interface Gate { key: GateKey; index: number; x: number; z: number; dx: number; dz: number; color: number }

export const GATES: Gate[] = [
  { key: "profile", index: 0, x: 140, z: 175, dx: 0, dz: 1, color: NEON.lime },
  { key: "skills", index: 1, x: 175, z: 210, dx: 1, dz: 0, color: NEON.cyan },
  { key: "experience", index: 2, x: 280, z: 105, dx: 0, dz: 1, color: NEON.magenta },
  { key: "projects", index: 3, x: 105, z: 0, dx: 1, dz: 0, color: NEON.violet },
  { key: "education", index: 4, x: 0, z: 175, dx: 0, dz: 1, color: NEON.amber },
  { key: "contact", index: 5, x: 175, z: 280, dx: 1, dz: 0, color: NEON.lime },
];

const ENTER_ALONG = 1.6, ENTER_ACROSS = ROAD_HALF + 0.5;
const EXIT_ALONG = 2.6, EXIT_ACROSS = ROAD_HALF + 1.5;

export function gateLocal(g: Gate, x: number, z: number) {
  const rx = x - g.x, rz = z - g.z;
  return { along: rx * g.dx + rz * g.dz, across: Math.abs(rx * g.dz - rz * g.dx) };
}

export const gateYaw = (g: Gate) => Math.atan2(g.dx, g.dz);

export function gatePillars(g: Gate): Circle[] {
  const yaw = gateYaw(g), ax = Math.cos(yaw), az = -Math.sin(yaw), off = ROAD_HALF + 1;
  return [-off, off].map((o) => ({ x: g.x + ax * o, z: g.z + az * o, r: 0.7 }));
}

/** Edge-triggered: reports a gate once when the rider enters it, again only after they have clearly left. */
export class GateTracker {
  private inside = new Set<GateKey>();

  update(x: number, z: number): GateKey[] {
    const entered: GateKey[] = [];
    for (const g of GATES) {
      const { along, across } = gateLocal(g, x, z);
      if (!this.inside.has(g.key)) {
        if (Math.abs(along) < ENTER_ALONG && across < ENTER_ACROSS) {
          this.inside.add(g.key);
          entered.push(g.key);
        }
      } else if (Math.abs(along) > EXIT_ALONG || across > EXIT_ACROSS) this.inside.delete(g.key);
    }
    return entered;
  }

  reset() {
    this.inside.clear();
  }
}

export function nearestUnvisited(x: number, z: number, visited: readonly GateKey[]): { gate: Gate; distance: number } | null {
  let best: { gate: Gate; distance: number } | null = null;
  for (const g of GATES) {
    if (visited.includes(g.key)) continue;
    const distance = Math.hypot(x - g.x, z - g.z);
    if (!best || distance < best.distance) best = { gate: g, distance };
  }
  return best;
}

import { GATE_KEYS, type GateKey } from "./gates";

export type Tier = "high" | "low";
export type Phase = "intro" | "loading" | "running" | "failed";
export interface Nav { key: GateKey; distance: number }
export interface WorldState {
  phase: Phase; attempts: number; visited: GateKey[]; card: GateKey | null; finished: boolean; freeRide: boolean;
  muted: boolean; tier: Tier; nav: Nav | null; kmh: number; toast: string | null; contextLost: boolean;
}

const MUTE_KEY = "kota-neon:muted";
const TOAST_GAP_MS = 2500;

export const INITIAL_STATE: WorldState = {
  phase: "intro", attempts: 0, visited: [], card: null, finished: false, freeRide: false,
  muted: false, tier: "high", nav: null, kmh: 0, toast: null, contextLost: false,
};

export function createWorldStore() {
  let memoryMuted: boolean | null = null;
  const readMuted = () => {
    try {
      return window.localStorage.getItem(MUTE_KEY) === "1";
    } catch {
      return memoryMuted ?? false;
    }
  };
  let state: WorldState = { ...INITIAL_STATE, muted: typeof window === "undefined" ? false : readMuted() };
  let lastToast = -Infinity;
  const listeners = new Set<() => void>();

  function set(patch: Partial<WorldState>) {
    const next = { ...state, ...patch };
    if ((Object.keys(patch) as (keyof WorldState)[]).every((k) => Object.is(state[k], next[k]))) return;
    state = next;
    listeners.forEach((l) => l());
  }

  return {
    getState: () => state,
    subscribe(l: () => void) {
      listeners.add(l);
      return () => listeners.delete(l);
    },
    setPhase: (phase: Phase) => set({ phase }),
    /** Start (or retry) loading the world; `attempts` keys the error boundary so a retry remounts it. */
    start: () => set({ phase: "loading", attempts: state.attempts + 1 }),
    enterGate(key: GateKey) {
      const first = !state.visited.includes(key);
      const visited = first ? [...state.visited, key] : state.visited;
      const finished = state.finished || (first && visited.length === GATE_KEYS.length && !state.freeRide);
      set({ visited, card: key, finished });
      return { first };
    },
    openCard: (key: GateKey) => set({ card: key }),
    closeCard: () => set({ card: null }),
    stayFree: () => set({ finished: false, freeRide: true }),
    reset: () => set({ visited: [], card: null, finished: false, freeRide: false, nav: null }),
    toggleMute() {
      const muted = !state.muted;
      try {
        window.localStorage.setItem(MUTE_KEY, muted ? "1" : "0");
      } catch {
        memoryMuted = muted;
      }
      set({ muted });
    },
    setTier: (tier: Tier) => set({ tier }),
    setNav(nav: Nav | null) {
      if (nav && state.nav && nav.key === state.nav.key && nav.distance === state.nav.distance) return;
      if (!nav && !state.nav) return;
      set({ nav });
    },
    setKmh: (kmh: number) => set({ kmh }),
    toast(message: string, now = Date.now()) {
      if (now - lastToast < TOAST_GAP_MS) return;
      lastToast = now;
      set({ toast: message });
    },
    clearToast: () => set({ toast: null }),
    setContextLost: (contextLost: boolean) => set({ contextLost }),
  };
}

export type WorldStore = ReturnType<typeof createWorldStore>;
export const worldStore = createWorldStore();

import { GATES, GateTracker, gatePillars, type GateKey } from "./gates";

import { mulberry32, type Rand } from "./random";
import type { Tier } from "./store";
import { pushBikeFromCars, spawnCars, stepTraffic, type Car } from "./traffic";

export interface Runtime {
  city: CityLayout;
  colliders: { rects: Rect[]; circles: Circle[] };
  bike: BikeState;
  input: BikeInput;
  cars: Car[];
  peds: Ped[];
  rand: Rand;
  shake: number;
  tracker: GateTracker;
}

export interface StepEvents { bump: boolean; honk: boolean; nearMiss: boolean; entered: GateKey[] }

export const AGENTS: Record<Tier, { cars: number; peds: number }> = { high: { cars: 18, peds: 44 }, low: { cars: 8, peds: 16 } };

export function createRuntime(tier: Tier, seed = 7): Runtime {
  const city = buildCity(seed);
  const circles = [...city.circles, ...GATES.flatMap(gatePillars), ...BOARDS.map(boardPole)];
  const rand = mulberry32(seed + 1);
  return {
    city,
    colliders: { rects: city.rects, circles },
    bike: createBike(START.x, START.z, START.heading),
    input: { gas: false, brake: false, left: false, right: false, boost: false },
    cars: spawnCars(AGENTS[tier].cars, rand),
    peds: spawnPeds(AGENTS[tier].peds, rand),
    rand,
    shake: 0,
    tracker: new GateTracker(),
  };
}

/** `keepBike` is for a mid-ride tier drop: respawn agents without teleporting the rider. */
export function resetRuntime(rt: Runtime, tier: Tier, keepBike = false) {
  if (!keepBike) rt.bike = createBike(START.x, START.z, START.heading);
  rt.cars = spawnCars(AGENTS[tier].cars, rt.rand);
  rt.peds = spawnPeds(AGENTS[tier].peds, rt.rand);
  rt.tracker.reset();
  rt.shake = 0;
}

/** One simulation tick. Rendering components only read from `rt` afterwards. */
export function stepWorld(rt: Runtime, rawDt: number, started: boolean): StepEvents {
  const dt = Math.min(Math.max(rawDt, 0), 1 / 30);
  const ev: StepEvents = { bump: false, honk: false, nearMiss: false, entered: [] };
  if (started) {
    let b = stepBike(rt.bike, rt.input, dt);
    const c = resolveCollisions(b.x, b.z, rt.colliders.rects, rt.colliders.circles, BOUNDS);
    if (c.hit) {
      ev.bump = Math.abs(b.v) > 4;
      b = { ...b, x: c.x, z: c.z, v: b.v * 0.35 };
    }
    rt.bike = b;
  }
  ev.honk = stepTraffic(rt.cars, rt.bike, dt, rt.rand).honked;
  if (started) {
    const p = pushBikeFromCars(rt.bike.x, rt.bike.z, rt.cars);
    if (p.hit) {
      if (Math.abs(rt.bike.v) > 2) ev.bump = true;
      rt.bike = { ...rt.bike, x: p.x, z: p.z, v: rt.bike.v * 0.3 };
    }
  }
  const peds = stepPeds(rt.peds, rt.bike, rt.bike.v, dt);
  if (started && peds.nearMiss) {
    rt.bike = { ...rt.bike, v: rt.bike.v * 0.6 };
    ev.nearMiss = true;
  }
  if (started) ev.entered = rt.tracker.update(rt.bike.x, rt.bike.z);
  if (ev.bump) rt.shake = 0.35;
  rt.shake = Math.max(0, rt.shake - dt * 1.5);
  return ev;
}

let singleton: Runtime | null = null;
/** App-wide mutable world (client only). */
export function getRuntime(tier: Tier = "high"): Runtime {
  if (!singleton) singleton = createRuntime(tier);
  return singleton;
}

export type Ctx = CanvasRenderingContext2D;

export function rr(g: Ctx, x: number, y: number, w: number, h: number, r: number) {
  g.beginPath();
  g.moveTo(x + r, y);
  g.arcTo(x + w, y, x + w, y + h, r);
  g.arcTo(x + w, y + h, x, y + h, r);
  g.arcTo(x, y + h, x, y, r);
  g.arcTo(x, y, x + w, y, r);
  g.closePath();
}

export const setFont = (g: Ctx, weight: number, size: number, family: string) => {
  g.font = `${weight} ${size}px ${family}`;
};

/** Shrinks the font until `text` fits `maxW`; returns the size used. */
export function fit(g: Ctx, text: string, maxW: number, size: number, weight: number, family: string): number {
  setFont(g, weight, size, family);
  while (g.measureText(text).width > maxW && size > 12) {
    size -= 2;
    setFont(g, weight, size, family);
  }
  return size;
}

/** Word-wraps with the current font; returns the y after the last line. */
export function wrap(g: Ctx, text: string, x: number, y: number, maxW: number, lineH: number, maxLines = 3): number {
  const words = text.split(" ");
  let line = "", lines = 0;
  for (const word of words) {
    const test = line ? `${line} ${word}` : word;
    if (g.measureText(test).width > maxW && line) {
      if (lines === maxLines - 1) {
        g.fillText(line + "…", x, y);
        return y + lineH;
      }
      g.fillText(line, x, y);
      y += lineH;
      lines++;
      line = word;
    } else line = test;
  }
  if (line) g.fillText(line, x, y);
  return y + lineH;
}

export function label(g: Ctx, text: string, x: number, y: number, color: string, mono: string) {
  setFont(g, 700, 22, mono);
  g.fillStyle = color;
  g.fillText(text.split("").join(String.fromCharCode(8202)), x, y);
}

export function chip(g: Ctx, text: string, x: number, y: number, color: string, mono: string, size = 24): number {
  setFont(g, 600, size, mono);
  const w = g.measureText(text).width + size * 1.3, h = size * 1.9;
  rr(g, x, y - h * 0.68, w, h, h / 2);
  g.strokeStyle = color;
  g.lineWidth = 2.5;
  g.stroke();
  g.fillStyle = color;
  g.fillText(text, x + size * 0.65, y + 2);

function buildingGeometry(w: number, h: number, d: number, x: number, z: number): BufferGeometry {
  const g = new BoxGeometry(w, h, d);
  const uv = g.attributes.uv;
  const faces = [[d, h], [d, h], [0, 0], [0, 0], [w, h], [w, h]];
  for (let f = 0; f < 6; f++)

/** Merges geometries grouped by a numeric key (material index or colour). */
export function mergeBy<T>(items: T[], key: (t: T) => number, geo: (t: T) => BufferGeometry | null) {
  const groups = new Map<number, BufferGeometry[]>();
  for (const it of items) {
    const g = geo(it);
    if (!g) continue;
    const k = key(it);
    if (!groups.has(k)) groups.set(k, []);
    groups.get(k)!.push(g);

```ts
"use client";

import { useEffect } from "react";
import type { BikeInput } from "@/world/bike";

const MAP: Record<string, keyof BikeInput> = {
  KeyW: "gas", ArrowUp: "gas", KeyS: "brake", ArrowDown: "brake", KeyA: "left", ArrowLeft: "left",
  KeyD: "right", ArrowRight: "right", ShiftLeft: "boost", ShiftRight: "boost",
};

export function useKeyboardInput(input: BikeInput, handlers: { onBell(): void; onEscape(): void }, enabled: boolean) {
  useEffect(() => {
    const release = () => {
      (Object.keys(input) as (keyof BikeInput)[]).forEach((k) => (input[k] = false));
    };
    if (!enabled) {
      release();
      return;
    }
    const down = (e: KeyboardEvent) => {
      const k = MAP[e.code];
      if (k) {
        input[k] = true;
        e.preventDefault();
      } else if (e.code === "Space") {
        e.preventDefault();
        if (!e.repeat) handlers.onBell();
      } else if (e.code === "Escape") handlers.onEscape();
    };
    const up = (e: KeyboardEvent) => {
      const k = MAP[e.code];
      if (k) input[k] = false;
    };
    const vis = () => {
      if (document.visibilityState === "hidden") release();
    };
    window.addEventListener("keydown", down);
    window.addEventListener("keyup", up);
    window.addEventListener("blur", release);
    document.addEventListener("visibilitychange", vis);
    return () => {
      window.removeEventListener("keydown", down);
      window.removeEventListener("keyup", up);
      window.removeEventListener("blur", release);
      document.removeEventListener("visibilitychange", vis);
      release();
    };
  }, [input, handlers, enabled]);
}
```

Callers must pass a stable `handlers` object (`useMemo`). Otherwise the listeners re-bind on every render.

import { BoxGeometry, CylinderGeometry, Group, type Material, Mesh, MeshBasicMaterial, MeshStandardMaterial, SphereGeometry, SpotLight, Sprite, SpriteMaterial, TorusGeometry, AdditiveBlending, Vector3 } from "three";
import type { BikeInput, BikeState } from "@/world/bike";
import { NEON } from "@/world/palette";
import { LIGHT } from "../lighting";
import { glowTexture } from "../painters/signs";

const UP = new Vector3(0, 1, 0);
const unitCyl = new CylinderGeometry(1, 1, 1, 8);
const unitBox = new BoxGeometry(1, 1, 1);
const tmp = new Vector3();
const V = (x: number, y: number, z: number) => new Vector3(x, y, z);

function place(mesh: Mesh, a: Vector3, b: Vector3, r: number) {
  tmp.subVectors(b, a);
  const len = tmp.length();
  mesh.position.copy(a).addScaledVector(tmp, 0.5);
  mesh.quaternion.setFromUnitVectors(UP, tmp.normalize());
  mesh.scale.set(r, len, r);
}

function rod(parent: Group, a: Vector3, b: Vector3, r: number, mat: Material) {
  const m = new Mesh(unitCyl, mat);
  place(m, a, b, r);
  parent.add(m);
  return m;
}

export function glowSprite(color: number, size: number, opacity = 1) {
  const s = new Sprite(new SpriteMaterial({ map: glowTexture(), color, opacity, transparent: true, depthWrite: false, blending: AdditiveBlending }));
  s.scale.set(size, size, 1);
  return s;
}

export function createBikeModel() {
  const frameM = new MeshStandardMaterial({ color: NEON.lime, emissive: 0x2c4a00, metalness: 0.5, roughness: 0.35 });
  const tyreM = new MeshStandardMaterial({ color: 0x0d0d14, roughness: 0.7 });
  const rimM = new MeshBasicMaterial({ color: NEON.cyan });
  const skinM = new MeshStandardMaterial({ color: 0xc98f6b, roughness: 0.7 });
  const shirtM = new MeshStandardMaterial({ color: 0x2b2550, roughness: 0.8 });
  const pantM = new MeshStandardMaterial({ color: 0x15131f, roughness: 0.8 });

  const fork = new Group();

  group.add(fork);

    const g = new Group();

    for (let i = 0; i < 4; i++) {

      sp.scale.set(0.015, 0.66, 0.015);
      sp.rotation.x = (i * Math.PI) / 4;
      g.add(sp);
    }
    parent.add(g);
    return g;
  };
  const rear = wheel(group, -0.62);
  const front = wheel(fork, 0.12);

  rod(group, V(0, 0.46, -0.62), crank, 0.035, frameM);
  rod(group, crank, seat, 0.04, frameM);
  rod(group, seat, head, 0.035, frameM);

  spot.position.set(0, 1.2, 0.7);

  group.add(rider);
  const hip = V(0, 1.2, -0.26), shoulder = V(0, 1.78, 0.14);
  rod(rider, hip, shoulder, 0.2, shirtM);
  const headM = new Mesh(new SphereGeometry(0.17, 14, 10), skinM);

  const legs = [-0.13, 0.13].map((x) => {
    const thigh = rod(group, V(0, 0, 0), V(0, 1, 0), 0.075, pantM);
    const shin = rod(group, V(0, 0, 0), V(0, 1, 0), 0.06, pantM);
    const foot = new Mesh(unitBox, tyreM);
    foot.scale.set(0.1, 0.07, 0.24);
    group.add(foot);
    return { x, thigh, shin, foot };
  });
  const crankArms = [rod(group, V(0, 0, 0), V(0, 1, 0), 0.025, rimM), rod(group, V(0, 0, 0), V(0, 1, 0), 0.025, rimM)];
  const LEG = 0.56;

  function pose(crankAngle: number) {
    legs.forEach((lg, i) => {
      const a = crankAngle + i * Math.PI;
      const pedal = V(lg.x * 1.4, crank.y + Math.sin(a) * 0.17, crank.z + Math.cos(a) * 0.17);
      place(crankArms[i], V(lg.x * 1.4, crank.y, crank.z), pedal, 0.025);
      const hp = V(lg.x, hip.y, hip.z);
      const d = hp.distanceTo(pedal), half = Math.min(d / 2, LEG * 0.999), off = Math.sqrt(LEG * LEG - half * half);
      const dir = pedal.clone().sub(hp).normalize();
      const perp = V(0, -dir.z, dir.y);
      if (perp.z < 0) perp.negate();
      const knee = hp.clone().addScaledVector(dir, half).addScaledVector(perp, off);
      place(lg.thigh, hp, knee, 0.075);
      place(lg.shin, knee, pedal, 0.06);
      lg.foot.position.copy(pedal).add(V(0, -0.02, 0.04));
    });
  }
  pose(0);
  return { group, fork, front, rear, rider, pose };
}

export type BikeModel = ReturnType<typeof createBikeModel>;

/** Per-frame pose (module-level so React's immutability lint does not see a hook value being mutated). */
export function applyBikePose(m: BikeModel, bike: BikeState, input: BikeInput, riding: boolean, dt: number) {
  m.group.position.set(bike.x, 0, bike.z);
  m.group.rotation.set(0, bike.heading, bike.lean);
  m.fork.rotation.y = bike.steer * 0.35;
  m.front.rotation.x += (bike.v * dt) / 0.46;
  m.rear.rotation.x += (bike.v * dt) / 0.46;
  m.rider.position.y = riding && input.gas ? Math.abs(Math.sin(bike.crank)) * 0.04 : 0;
  m.rider.rotation.x = Math.min(0.18, Math.max(0, bike.v) * 0.006 + (input.boost ? 0.08 : 0));
  m.pose(bike.crank);
}

"use client";

import { useEffect, useMemo, useRef } from "react";
import { useFrame } from "@react-three/fiber";
import { useLanguage } from "@/context/LanguageContext";
import { kmh } from "@/world/bike";
import { nearestUnvisited } from "@/world/gates";
import { getRuntime, stepWorld } from "@/world/runtime";
import { worldStore } from "@/world/store";
import { useWorld } from "@/world/useWorld";
import { useKeyboardInput } from "./useKeyboardInput";

export interface SoundHooks { onBell?: () => void; onChime?: () => void; onHorn?: () => void; onBump?: () => void }

declare global {
  interface Window { __world?: { tp(x: number, z: number, heading: number): void } }
}

/** The single per-frame simulation tick (priority -1 runs before every renderer). */
export function Simulation({ onBell, onChime, onHorn, onBump }: SoundHooks) {
  const { ui } = useLanguage();
  const hud = useRef(ui.world.hud);
  useEffect(() => {
    hud.current = ui.world.hud;
  }, [ui]);
  const phase = useWorld((s) => s.phase);

  const handlers = useMemo(() => ({ onBell: () => onBell?.(), onEscape: () => worldStore.closeCard() }), [onBell]);
  useKeyboardInput(getRuntime().input, handlers, phase === "running");

  useEffect(() => {
    if (process.env.NODE_ENV === "production" && process.env.NEXT_PUBLIC_E2E !== "1") return;
    window.__world = {
      tp: (x, z, heading) => {
        const r = getRuntime();
        r.bike = { ...r.bike, x, z, heading, v: 0 };
      },
    };
    return () => {
      delete window.__world;
    };
  }, []);

  useFrame((_, dt) => {
    const rt = getRuntime();
    const s = worldStore.getState();
    const ev = stepWorld(rt, dt, s.phase === "running" && !s.contextLost);
    for (const key of ev.entered) if (worldStore.enterGate(key).first) onChime?.();
    if (ev.bump) {
      onBump?.();
      worldStore.toast(hud.current.toastObstacle);
    }
    if (ev.honk) {
      onHorn?.();
      worldStore.toast(hud.current.toastCar);
    }
    if (ev.nearMiss) worldStore.toast(hud.current.toastPed);
    worldStore.setKmh(kmh(rt.bike.v));
    const n = nearestUnvisited(rt.bike.x, rt.bike.z, worldStore.getState().visited);
    worldStore.setNav(n ? { key: n.gate.key, distance: Math.round(n.distance) } : null);
  }, -1);
  return null;
}

"use client";

import { useRef } from "react";
import { useFrame, useThree } from "@react-three/fiber";
import { useReducedMotion } from "motion/react";
import { type PerspectiveCamera, Vector3 } from "three";
import { forward } from "@/world/bike";
import { getRuntime } from "@/world/runtime";
import { worldStore } from "@/world/store";

function shakeCamera(cam: PerspectiveCamera, amount: number) {
  cam.position.x += (Math.random() - 0.5) * amount;
  cam.position.y += (Math.random() - 0.5) * amount;
}

function easeFov(cam: PerspectiveCamera, fov: number, dt: number) {
  if (Math.abs(cam.fov - fov) <= 0.05) return;
  cam.fov += (fov - cam.fov) * Math.min(1, dt * 3);
  cam.updateProjectionMatrix();
}

/** Idle orbit on the intro; spring follow with look-ahead, speed FOV and bump shake while riding. */
export function CameraRig() {
  const reduce = useReducedMotion() ?? false;
  const camera = useThree((s) => s.camera) as PerspectiveCamera;
  const size = useThree((s) => s.size);
  const pos = useRef(new Vector3());
  const look = useRef(new Vector3());
  const lookS = useRef(new Vector3());
  const angle = useRef(0);
  const first = useRef(true);

  useFrame((_, raw) => {
    const dt = Math.min(raw, 1 / 30);
    const rt = getRuntime();
    const b = rt.bike;
    const riding = worldStore.getState().phase === "running";
    const f = forward(b.heading);
    const v = Math.max(0, b.v);
    if (!riding) {
      angle.current += dt * (reduce ? 0 : 0.16);
      pos.current.set(b.x + Math.sin(angle.current) * 9, 3.6, b.z + Math.cos(angle.current) * 9);
      lookS.current.set(b.x, 1.3, b.z);
    } else {
      const back = 6.4 + v * 0.07;
      pos.current.set(b.x - f.x * back, 3 + v * 0.025, b.z - f.z * back);
      look.current.set(b.x + f.x * (5 + v * 0.2), 1.2, b.z + f.z * (5 + v * 0.2));
      lookS.current.lerp(look.current, 1 - Math.exp(-dt * 8));
    }
    if (first.current) {
      camera.position.copy(pos.current);
      lookS.current.set(b.x, 1.3, b.z);
      first.current = false;
    }
    camera.position.lerp(pos.current, 1 - Math.exp(-dt * (riding ? 5 : 2)));
    if (rt.shake > 0 && !reduce) shakeCamera(camera, rt.shake);
    camera.lookAt(lookS.current);
    easeFov(camera, (size.width < size.height ? 74 : 62) + v * 0.38, dt);
  });
  return null;
}

export function Minimap() {
  const ref = useRef<HTMLCanvasElement>(null);
  useEffect(() => {
    const g = ref.current?.getContext("2d");
    if (!g) return;
    let raf = 0, last = 0;
    const park = BLOCKS.find((b) => b.park)!;
    const boards = BOARDS.map((b) => ({ ...placeBoard(b), color: b.color }));
    const draw = (t: number) => {
      raf = requestAnimationFrame(draw);
      if (t - last < 1000 / 15) return;
      last = t;
      const rt = getRuntime();
      const visited = worldStore.getState().visited;
      g.clearRect(0, 0, MINIMAP_PX, MINIMAP_PX);
      g.strokeStyle = "rgba(160,150,255,.35)";
      g.lineWidth = ROAD_HALF * 2 * MINIMAP_SCALE;
      g.lineCap = "square";
      for (const s of SEGMENTS) {
        const a = toMinimap(s.a.x, s.a.z), b = toMinimap(s.b.x, s.b.z);
        g.beginPath();
        g.moveTo(a.mx, a.my);
        g.lineTo(b.mx, b.my);
        g.stroke();
      }
      const p0 = toMinimap(park.x1, park.z1);
      g.fillStyle = "rgba(34,211,154,.25)";
      g.fillRect(p0.mx, p0.my, (park.x1 - park.x0) * MINIMAP_SCALE, (park.z1 - park.z0) * MINIMAP_SCALE);
      g.fillStyle = "rgba(236,234,255,.55)";
      for (const c of rt.cars) {
        const m = toMinimap(c.pos.x, c.pos.z);
        g.fillRect(m.mx - 3, m.my - 3, 6, 6);
      }
      for (const b of boards) {
        const m = toMinimap(b.x, b.z);
        g.fillStyle = hex(b.color);
        g.fillRect(m.mx - 5, m.my - 5, 10, 10);
      }
      for (const gt of GATES) {
        const m = toMinimap(gt.x, gt.z), done = visited.includes(gt.key);
        g.beginPath();
        g.arc(m.mx, m.my, 10, 0, Math.PI * 2);
        g.globalAlpha = done ? 0.5 : 1;
        g.fillStyle = hex(done ? NEON.lime : gt.color);
        g.fill();
        g.globalAlpha = 1;
      }
      const me = toMinimap(rt.bike.x, rt.bike.z);
      g.save();
      g.translate(me.mx, me.my);
      g.rotate(minimapRotation(rt.bike.heading));
      g.beginPath();
      g.moveTo(0, -16);
      g.lineTo(10, 12);
      g.lineTo(0, 6);
      g.lineTo(-10, 12);
      g.closePath();
      g.fillStyle = "#fff";
      g.shadowColor = hex(NEON.lime);
      g.shadowBlur = 12;
      g.fill();
      g.restore();
    };
    raf = requestAnimationFrame(draw);
    return () => cancelAnimationFrame(raf);
  }, []);

      width={MINIMAP_PX}

const box = new BoxGeometry(1, 1, 1);

    tg.position.set(x, 0.8, -2.3);
    g.add(tg);

  if (taxi) part(g, new MeshBasicMaterial({ color: NEON.lime }), [0.7, 0.25, 0.35], [0, 1.8, -0.3]);

export function boardTexture(face: BoardFace, spec: BoardSpec, content: PortfolioContent, ui: UiStrings, f: Fonts): CanvasTexture {
  const tall = spec.form === "tall";
  const w = tall ? 512 : 1024, h = tall ? 768 : 512;
  const cv = document.createElement("canvas");
  cv.width = w;
  cv.height = h;
  const g = cv.getContext("2d")!;
  const c = hex(spec.color);
  const bg = g.createLinearGradient(0, 0, w * 0.4, h);
  bg.addColorStop(0, "#15123a");
  bg.addColorStop(1, "#08071a");
  g.fillStyle = bg;
  g.fillRect(0, 0, w, h);
  g.globalAlpha = 0.07;
  g.fillStyle = c;
  for (let y = 0; y < h; y += 6) g.fillRect(0, y, w, 1);
  g.globalAlpha = 1;
  g.textBaseline = "alphabetic";
  g.textAlign = "left";
  const resolved = resolveFace(face, content);
  PAINT[resolved.design]({ g, w, h, c, f, content, ui, face: resolved });
  g.strokeStyle = c;
  g.lineWidth = 6;
  g.strokeRect(3, 3, w - 6, h - 6);
  const t = new CanvasTexture(cv);
  t.colorSpace = SRGBColorSpace;
  t.anisotropy = 8;
  return t;
}

import { worldStore } from "@/world/store";

type Wave = OscillatorType;

/** Synthesised UI sounds; nothing plays before a user gesture or while muted. */
export function createAudio() {
  let ctx: AudioContext | null = null;
  function tone(freq: number, dur: number, type: Wave = "sine", vol = 0.15, delay = 0) {
    if (!ctx || worldStore.getState().muted) return;
    const t0 = ctx.currentTime + delay;
    const o = ctx.createOscillator(), g = ctx.createGain();
    o.type = type;
    o.frequency.setValueAtTime(freq, t0);
    g.gain.setValueAtTime(0, t0);
    g.gain.linearRampToValueAtTime(vol, t0 + 0.01);
    g.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
    o.connect(g).connect(ctx.destination);
    o.start(t0);
    o.stop(t0 + dur + 0.05);
  }
  return {
    unlock() {
      try {
        const Ctor = window.AudioContext ?? (window as unknown as { webkitAudioContext?: typeof AudioContext }).webkitAudioContext;
        if (!ctx && Ctor) ctx = new Ctor();
        void ctx?.resume?.();
      } catch {
        ctx = null;
      }
    },
    bell: () => (tone(2093, 0.5, "triangle", 0.12), tone(2637, 0.45, "triangle", 0.08, 0.08), tone(2093, 0.5, "triangle", 0.1, 0.22)),
    chime: () => (tone(660, 0.4, "sine", 0.12), tone(880, 0.4, "sine", 0.1, 0.1), tone(1320, 0.6, "sine", 0.08, 0.2)),
    horn: () => (tone(392, 0.35, "square", 0.05), tone(494, 0.35, "square", 0.04)),
    bump: () => tone(110, 0.18, "sine", 0.2),
  };
}

export type WorldAudio = ReturnType<typeof createAudio>;

"use client";

import dynamic from "next/dynamic";
import { useEffect, useMemo } from "react";
import { createAudio } from "@/components/world/audio";
import { useWebGLSupport } from "@/hooks/useWebGLSupport";
import { getRuntime } from "@/world/runtime";
import { worldStore, type Tier } from "@/world/store";
import { useWorld } from "@/world/useWorld";
import { ContextLost } from "./ContextLost";
import { Hud } from "./Hud";
import { Intro } from "./Intro";
import { WorldErrorBoundary } from "./WorldErrorBoundary";

const load = () => import("@/components/world/WorldCanvas");
const WorldCanvas = dynamic(load, { ssr: false, loading: () => null });

const initialTier = (): Tier => (window.matchMedia("(pointer: coarse)").matches ? "low" : "high");

export function WorldGate() {
  const phase = useWorld((s) => s.phase);
  const attempts = useWorld((s) => s.attempts);
  const contextLost = useWorld((s) => s.contextLost);
  const webgl = useWebGLSupport();
  const audio = useMemo(() => createAudio(), []);
  const running = phase === "running";

  // Warm the world chunk while the visitor reads the intro (desktop only).
  useEffect(() => {
    if (!webgl || initialTier() === "low") return;
    const warm = () => void load().catch(() => {});
    if ("requestIdleCallback" in window) {
      const id = window.requestIdleCallback(warm);
      return () => window.cancelIdleCallback(id);
    }
    const t = window.setTimeout(warm, 1500);
    return () => window.clearTimeout(t);
  }, [webgl]);

  useEffect(() => {
    if (phase !== "loading") return;
    const tier = initialTier();
    worldStore.setTier(tier);
    getRuntime(tier);
    audio.unlock();
  }, [phase, audio]);

  const sounds = useMemo(() => ({ onBell: audio.bell, onChime: audio.chime, onHorn: audio.horn, onBump: audio.bump }), [audio]);

  return (
    <>
      {(phase === "loading" || running) && (
        <WorldErrorBoundary key={attempts} onError={() => worldStore.setPhase("failed")}>
          <WorldCanvas onReady={() => worldStore.setPhase("running")} sounds={sounds} />
        </WorldErrorBoundary>
      )}
      {running && <Hud onBell={audio.bell} />}
      {running && contextLost && <ContextLost />}
      <Intro hidden={running} />
    </>
  );
}
